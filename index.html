How to Use Prince Simulator

Getting Started

  1. Pick an experiment from the dropdown in the Editor panel
  2. Click Compile & Load to assemble the code into memory
  3. Hit Run to execute, or Step to go one instruction at a time
  4. Check the Registers panel to see CPU state changes in real-time
  5. Use the Memory Table to inspect and edit raw memory bytes

The Trainer Board

This is a digital twin of the physical 8085 lab kit. Switch to the Trainer Board Kit tab and use your keyboard exactly like you would in the lab:

  • M — Enter address mode (type a 4-digit hex address)
  • D — Switch to data entry (type hex byte values)
  • Enter / Arrow Right — Save and move to next address
  • Backspace / Arrow Left — Go back one address
  • G — Execute program starting from current address
  • S — Single-step one instruction
  • E — Examine register values (then press A-F, H, L)
  • R / Esc — Hardware reset

Typical Lab Workflow

  1. Switch to Trainer Board tab
  2. Press M and type 2000 to set the start address
  3. Press D to enter data mode
  4. Type your opcode bytes one by one, pressing Enter after each
  5. When done, press M again, type the start address
  6. Press G twice to execute
  7. Press E then A to check the Accumulator result

Pro Tips

  • The Fullscreen button in the Trainer tab gives you an immersive experience
  • Use the Speed slider in the Registers panel to slow down execution for debugging
  • The console log at the bottom of the Editor tracks every action
  • Memory cells are editable — click any hex byte in the Memory Table to change it
